## Issues discovered
- Doc vs prototype: A08/A16/A20 write 'Get Started →', 'Sign in →', 'Create account →'. In the prototype the welcome/intro arrow is `display:none` and the auth arrow is a separate absolutely positioned span. Implemented the visible look exactly and exposed the doc string as the semantics label (tests use `bySemanticsLabel`).
- Prototype quirks kept: personalize options only toast (the preselected 'Smart casual' never moves); the HTML `minlength` makes the 'short password' message unreachable natively, doc A03 makes it reachable here.
- Prototype `intro` index 5 crash (personalize back after last slide) avoided: slide stays at 4.
- Decision: Android back on intro steps back a slide (PopScope -> cubit.back()), personalize back -> /intro. Not recorded in `.memory/decisions/`.
- Email validation is `^[^@\s]+@[^@\s]+\.[^@\s]+$` (rejects 'a@b' per A06, stricter than HTML type=email).
- `GoRouter.routerDelegate.currentConfiguration.uri` does not reflect `push`ed routes; tests use `.last.matchedLocation`.
- No `DemoNote` used: the prototype shows no separate disclaimer on these screens (notices are inline copy).
