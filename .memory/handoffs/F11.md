## Issues discovered
- `lib/features/shopping/shopping_routes.dart` and `lib/features/insights/insights_routes.dart` already existed as `GenericPreviewView` placeholders wired into `app_router.dart` before I started — some earlier setup step (not a sibling agent, this was present at task start) had stubbed them in advance. I overwrote the shopping one; the insights one is out of my scope and untouched.
- `GridView.count` with `childAspectRatio: 1.0` (the implicit default) overflowed inside `ShOwnedGrid` at 3 columns because the garment image (83px) plus caption didn't fit a square cell at this viewport width; fixed with `childAspectRatio: .72`. Worth double-checking visually against the prototype screenshot once Playwright/live-run parity is available (gate 4).
- `Row(crossAxisAlignment: stretch)` inside a `Container` with only `minHeight` (no fixed height) produces an unbounded-height layout exception in Flutter when a descendant stretches; fixed by giving `ShSuggestionCard`'s outer `Container` a fixed `height: 137` instead of a `BoxConstraints(minHeight: 137)`. Noting this pattern in case other feature agents hit the same issue with similar card layouts.
- `find.text()` does not match text rendered via `RichText`/`TextSpan` by default; `ShTabs` renders "Discover 5" / "Wishlist 0" as two `TextSpan`s inside one `RichText` (to color the count differently from the label, matching `.sh-tabs span{opacity:.7}`). Tests use `find.text(..., findRichText: true)` to find/tap these. Flagging in case this choice needs to be consistent with how other features test similar "label + count" tab compositions.
