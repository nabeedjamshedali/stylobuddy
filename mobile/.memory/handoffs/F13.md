## Issues discovered
- `PfChoiceGrid` and the plan-card `Row` both originally used
  `crossAxisAlignment: CrossAxisAlignment.stretch` directly inside an
  unbounded-height `Column` (inside `SingleChildScrollView`), which threw
  `BoxConstraints forces an infinite height` at layout time. Fixed by
  wrapping each such `Row` in `IntrinsicHeight`. Worth remembering for any
  other feature that pairs `Expanded` + `stretch` inside a scroll view.
- The prototype's `menuRow` subtitle for "Style preferences" on `/profile`
  joins styles with `' · '` (middle dot), while `ProfileState.styleSummary`
  (used nowhere else in the UI per the doc) joins with `' • '` (bullet) —
  two different glyphs for two different call sites in `app.js`. Handled
  by *not* using `styleSummary` for that row; it's built inline from
  `state.styles.join(' · ')` instead. Flagged here since it's an easy spot
  to accidentally "fix" into consistency and break A04/A11.
- No changes were needed to `ProfileCubit`/`ProfileState`
  (`lib/features/profile/cubit/`), `AppRoutes` (`lib/core/router/
  app_routes.dart` — `tabFor`/`_profileGroup` already matched A27 exactly),
  or `lib/app.dart`. Confirmed these already matched the feature document
  before writing any profile UI.
- Scope was kept strictly to `lib/features/profile/**` and its test; did
  not touch `lib/features/shopping/**` or `lib/features/insights/**`
  (sibling sub-features of plan task 13, completed separately).
