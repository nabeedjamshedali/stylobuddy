## Issues discovered
- `BlockSemantics` from route modal barriers dropped the banners from the accessibility tree when
  they were painted before the Navigator in the same semantics container; fixed by giving the app
  child its own `Semantics(container: true)` in the banner layout (only in that branch).
- `RepositoryProvider.of` rethrows a missing provider as `FlutterError`, so `analyticsOf` uses
  `context.read` and catches `ProviderNotFoundException`.
- Interface refinement during build: `skip(OnboardingSkipPoint)` became `skipFromWelcome()` /
  `skipFromIntro()` so no view imports `lib/shared/backend/` (doc and A34 updated, dated note).
- `pub get` regenerated linux/macos/windows plugin registrants (url_launcher, package_info_plus).
- Out of scope, noticed: `docs/tracker.md` still lists Crashlytics as open although `main.dart`
  wires it; release builds are signed with the debug key (F25 §13 Q4); a parallel session added
  `docs/features/F26-real-ai-stylist.md` (a likely consumer of `ai_stylist_enabled`).
