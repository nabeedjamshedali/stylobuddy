## Issues discovered
- **Brief vs. feature-doc conflict (documented per the implementer contract, feature doc
  wins):** the plan brief's interface surface says match-select/match-review reuse the
  shared `ItemTileGrid(showLock: true)` (3-column grid, ✓-only mark, 🔒 lock glyph, no
  "+" mark, category-only caption, no color). The feature doc's assertions (F04-A05,
  F04-A06, F04-A08, F04-A09, F04-A10) and the prototype source
  (`P/app.js:152,155`, `P/styles.css:342` `.mm-items`/`.mm-item`/`.mm-check`/
  `.mm-lock-symbol`) require a **2-column** grid, a "+"/"✓" mark on match-select, a
  "category · color" caption, and a "◆"/"◇" mark with "Required in every
  look"/"Flexible candidate" captions on match-review — none of which the shared
  `ItemTileGrid` renders. I built feature-local `MmSelectGrid` / `MmLockGrid` instead of
  reusing `ItemTileGrid`, matching the prototype and the assertions exactly. No changes
  were made to the shared `ItemTileGrid` (still used as-is by F03/F07).
- `SelectField` (shared widget) displays an out-of-list current value verbatim instead of
  falling back to the first option (needed for F04-A13's "Casual Day Out" case). I did
  not change the shared widget; `MatchOptionsView` computes the effective fallback value
  itself before handing it to `SelectField`, and only commits it to `StylistCubit` when
  "✧ Find my best matches" is tapped (mirroring the prototype's native `<select>`
  fallback-until-selected behavior exactly). Shared-widget behavior unchanged for other
  callers.
- `GridView` tiles needed `childAspectRatio: 0.66` (not a value directly in the CSS,
  which uses fixed pixel heights) to avoid `RenderFlex` overflow with two lines of
  caption text at mobile width; purely a layout-fit choice, no assertion depends on the
  exact ratio.
- **Review fix (2026-10-17):** `MmSelectGrid` and `MmLockGrid` were near-duplicate
  widgets (~134 lines each, same grid/tile/badge structure, differing only in glyphs and
  caption text). Merged into one `lib/features/matching/widgets/mm_items_grid.dart` with
  `MmItemsGrid(mode: MmGridMode.select|lock, ids, marked, onTap)`; glyph and caption are
  derived from `mode` + tile state. Call sites in `match_select_view.dart` and
  `match_review_view.dart` updated accordingly. No behavior change; all 25 F04 tests and
  the full 162-test suite still pass, `flutter analyze` clean. See the "Fix report"
  section appended to `task-7-report.md` for full detail.
